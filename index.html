🗺️ คู่มือศึกษาโครงสร้างเกม Final Slop (Architecture Guide)

เกมนี้เป็นเกม 2.5D Isometric Web MMORPG ที่เรนเดอร์ในมุมมอง Isometric ด้วยเอนจิ้น Three.js และขับเคลื่อนระบบ Multiplayer ด้วย Colyseus:

1. Game Engine & Renderer

  • Three.js (WebGL): จัดการฉาก 3 มิติ, มุมมองกล้อง Orthographic/Perspective, ท่อไอคอน/เงา และเอฟเฟกต์แสง
  • Procedural Synthesizer: ระบบเสียง yF สังเคราะห์เสียงทั้งหมดด้วย Web Audio API สดๆ ไม่ต้องใช้ไฟล์ MP3 ขนาดใหญ่
  • 2D Billboard Sprites: ตัวละครและมอนสเตอร์ใช้เทคนิค 2.5D Sprite Sheets หันหน้า 4-8 ทิศทาง

2. Networking & State Management

  • Colyseus Room town: จัดการการเชื่อมต่อผ่าน WebSocket และประสานสถานะ players, monsters, drops
  • Client Message Types: move, attack, chat, bag, skill, warpTown

3. การควบคุม (Controls) & คำสั่งพิเศษ

  • PC Keyboard: W A S D หรือปุ่มลูกศร เพื่อเดิน, Spacebar หรือ J โจมตี, E คุยกับ NPC, H เปิดบอทออโต้
  • Mouse: คลิกที่พื้นเพื่อเดินไปยังจุดเป้าหมาย (Click-to-Move) หรือคลิกมอนสเตอร์เพื่อโจมตี
  • Mobile / Touch: จอยสติ๊กเสมือนมุมซ้ายล่าง และปุ่มแอ็กชันมุมขวาล่าง
